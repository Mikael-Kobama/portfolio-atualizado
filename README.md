## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu **portfólio pessoal**, desenvolvido do zero com HTML, CSS e JavaScript puro — sem frameworks de UI, apenas habilidade e atenção aos detalhes.

O site apresenta minha trajetória como desenvolvedor, minhas habilidades técnicas, projetos realizados e formação acadêmica, com uma interface moderna, responsiva e com suporte a tema escuro/claro.

---

## ✨ Funcionalidades

- 🌙 **Tema Escuro / Claro** — alternância com persistência via `localStorage`
- 📱 **Design Responsivo** — adaptado para mobile, tablet e desktop
- 🎯 **Filtro de Projetos** — filtre por Front-end ou Back-end
- 🪗 **Accordion de Skills** — seções expansíveis por categoria
- 🔗 **Navegação suave** — scroll behavior e link ativo automático
- ⬆️ **Botão Scroll Up** — aparece ao rolar a página
- 🎞️ **Animações Fade-up** — elementos animados ao entrar na tela

## ⚙️ Como Rodar Localmente

```bash
# Clone o repositório
git clone https://github.com/Mikael-Kobama/portfolio.git

# Entre na pasta
cd portfolio

# Abra no navegador (sem necessidade de servidor)
# Basta abrir o index.html diretamente, ou usar uma extensão como Live Server no VS Code
```

> **Dica:** Para melhor experiência durante o desenvolvimento, use a extensão **Live Server** no VS Code. Clique com o botão direito no `index.html` → _Open with Live Server_.
